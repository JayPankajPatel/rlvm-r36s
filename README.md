# rlvm for R36S-class ArkOS handhelds

Build scripts and patches to compile [rlvm](https://github.com/eglaysher/rlvm) for aarch64 ArkOS (Ubuntu 19.10 userland). Contains no game data. Bring your own legally obtained copy of a RealLive game.

rlvm is GPL-3.0-or-later; the patches here are under the same terms.
